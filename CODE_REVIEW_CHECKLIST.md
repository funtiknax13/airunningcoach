- [x] **SSRF: DNS rebinding в проверке внешних URL** — `backend/app/services/safe_fetch.py:24`

Проверено: живой внешний HTTPS всё ещё скачивается через закреплённый IP; `localhost`/`127.0.0.1`/внутренний docker-хостнейм (`postgres`) по-прежнему отклоняются на этапе валидации.

## ⚪ Низкий / edge-case / мёртвый код

- [ ] **Push-подписку можно тихо переприсвоить другому пользователю** — `backend/app/routers/push.py:20`
  Поиск существующей подписки идёт по `endpoint`, без привязки к текущему юзеру.
  → Низкая эксплуатируемость (endpoint обычно непредсказуем), но IDOR-паттерн налицо.

- [ ] **Strava dedup по временному окну может перезаписать чужую активность** — `backend/app/routers/strava_webhook.py:90`
  Новое `create`-событие ищет "любую" активность в ±1 минуту и переписывает её `strava_id`.
  → Две близкие по времени активности (брик-тренировка, два синхронизирующихся девайса) — вторая тренировка теряется.

- [ ] **`_is_rate_limit()` — хрупкое совпадение по подстроке "429"** — `backend/app/services/ai_agent.py:135`
  Фолбэк `" 429" in f" {e}"` сработает на любой ошибке, где "429" случайно встретилось в тексте.

- [ ] **Сплиты по км могут тихо показать `0:00/км`** — `backend/app/services/gpx_parser.py`
  `pace = elapsed_min / seg_dist` без проверки `elapsed_min > 0` при дублирующихся/невозрастающих таймстампах.
